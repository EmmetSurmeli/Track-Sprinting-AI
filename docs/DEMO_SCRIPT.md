# Simple demo walkthrough

1. Start at **Your sprint profile**. Enter your real details and goal, then **Save profile & continue**. These remain saved for the second upload.
2. Upload **IMG_7190.mov** (pants and hat). Click **Analyze my run**, then show the body-tracked video. The prepared five-second passage is available only after the exact upload; the app labels saved tracking honestly.
3. Click **Explain my technique**. Show **Technique analysis**, **What it means**, **Your focus**, and **Training to discuss**. The report identifies a landing position worth reviewing and a coordination drill; it does not diagnose a weak muscle.
4. Briefly open **Why this feedback? Measurements & sources**, then the frame viewer under **Explore your tracking & data**. Show that the explanation connects to an actual source frame.
5. Use **New video** in the sidebar, upload **IMG_2811.mov** (shirtless), and repeat. Your profile remains saved. Describe what each report actually finds; neither receives a scripted better/worse label.
6. Optionally open **Calendar & progress** to show both dated entries, then show the repository and tests.

Keep the recording around two to three minutes unless the application specifies a different limit. Saved tracking and cached AI reports are genuine prior computations, not live generation; say so when demonstrating reuse. Profile changes request a new report. Never show the API key. The initial landing review was selected manually, not automatically detected.

Detailed second-recording provenance and limits: [SECOND_CLIP_DEMO.md](SECOND_CLIP_DEMO.md). The repository excludes private videos, profiles, API keys and local artifact caches. Upload, commit and application submission are separate steps; the app does not publish anything.
